# 饮品热点雷达｜公开工程源码

这是饮品热点雷达的公开工程分支，按“数据抓取 → 数据清洗 → 网页呈现”三步组织。它用于审阅方法、修改规则和运行公开网页；线上页面仍由 `main` 分支独立部署。

- [查看线上页面](https://yajunmonk.github.io/beverage-hotspot-radar/)
- [查看部署分支](https://github.com/YajunMonk/beverage-hotspot-radar/tree/main)
- 当前版本：`V1.1 / 2026-W30`

## 三步结构

| 步骤 | 目录 | 公开内容 |
|---|---|---|
| 1. 数据抓取 | [01_数据抓取](01_数据抓取/README.md) | 来源职责、抓取漏斗、时间窗口、去重和停止线 |
| 2. 数据清洗 | [02_数据清洗](02_数据清洗/README.md) | 三大主题、标签、筛选和统计边界 |
| 3. 网页呈现 | [03_网页呈现](03_网页呈现/README.md) | 已脱敏的页面源码与公开数据快照 |
| 工程工具 | [99_工程工具](99_工程工具/README.md) | 公开包构建和页面验收脚本 |

## 当前公开结果

- 9 个品牌、94 条品牌内容证据、35 个去重行业事件；
- 产品动作 20、联名合作 9、品牌事件 15，主题允许重叠；
- 10 条三方线索、19 条 KOC 线索和 3 条热点选题只进入发现层，不改变本期 KPI；
- 页面数据中的小红书链接均已去除临时访问参数。

## 公开边界

本分支不包含 `90_历史归档`、原始抓取证据、内部运行记录、原始 Excel、完整处理工作簿、工程预览和本机状态文件。这样既能公开方法和可运行页面，也不会把短时效访问参数或历史内部材料写入 Git 历史。

因此，本分支可以审阅、修改和运行公开页面，但不能脱离本地私有输入重建全部抓取与清洗链路。详细边界见 [PUBLICATION_BOUNDARY.md](PUBLICATION_BOUNDARY.md)。

## 本地预览

进入 `03_网页呈现/V1.1` 后启动任意静态文件服务，即可打开 `index.html`。公开发布包可由 `99_工程工具/scripts/build_public_release.mjs` 重新生成。
