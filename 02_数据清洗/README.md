# 第二步：数据清洗与分析

本目录把第一步保留的原始证据，转换为可分析、可复核、可导入 BI、可渲染网页的正式数据。规则、事实、判断、指标和质量记录分开保存，避免把模型判断或人工结论直接写回原始数据。

## V1.2 当前结果

- 94 条品牌官号内容归并为 35 个去重事件，覆盖 9 个品牌。
- 74 个有效实体；1 个被驳回的历史错误实体保留为停用审计记录。
- 54 个标签定义、162 条标签判定、25 行网页重点标签指标。
- V1.1 遗留的 39 个待复核项全部逐项处理，其中 4 条错误实体关系被驳回；当前队列为 0。
- 三方 10 条、KOC 19 条和热点 3 条独立保存，不进入品牌事件与互动 KPI。
- 245 项发布校验全部通过；当前有 3 类非阻断数据限制被显性披露。

## 修改方式

1. 修改原始来源或抓取结果时，回到[第一步](../01_数据抓取/README.md)。
2. 修改字段、指标、标签或筛选边界时，先更新相应字典和正式规范。
3. 重新运行 V1.2 构建器，生成 CSV、JSON、分析结论和网页数据。
4. 重新生成 Excel，并运行发布校验器；校验不通过时不得更新网页入口。

不要直接手改自动生成的 CSV、JSON、Excel 或网页数据。V1.1 是冻结输入，新版本只能写入 V1.2 或更高版本目录。
