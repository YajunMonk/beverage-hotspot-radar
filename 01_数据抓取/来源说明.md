## 2. 清洗与去重规则

1. 以“来源类型 + 小红书 profile ID”作为去重键，不跨来源类型误合并账号。
2. 主页链接保留稳定的 `https://www.xiaohongshu.com/user/profile/<profile_id>`，移除
   `xsec_token`、`wechatWid`、`m_source` 等临时参数；带参数的原始链接只在本地用于追溯。
3. 账号 ID 一律按字符串保存，避免长数字在表格中被科学计数法或自动取整破坏。
4. 账号名称只去除首尾空格，不擅自修正括号、版本描述或账号中的表情符号。
5. 美食垂类的 5 条重复行被合并到首次出现的来源记录，并保留原始行号与重复次数。

`primary_source_id`、`source_post_url`、`published_at`、`captured_at` 和
`review_status`。只有 `review_status=approved` 且原帖链接完整的选题才进入页面。
