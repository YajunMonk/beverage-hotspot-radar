# 工程工具

本目录负责可重复构建、校验和验收，不保存另一份业务真相。业务人员从根目录 [README](../README.md) 进入；只有需要重建版本时才使用这里。

## V1.2 三个正式入口

1. `scripts/build_v1_2_release.mjs`：从冻结的 V1.1 输入生成 V1.2 主数据、事实表、复核表、指标、分析、BI 和页面数据。
2. `scripts/build_v1_2_workbook.mjs`：从 V1.2 CSV/JSON 生成 16 表 Excel 数据中心，并逐表检查和渲染。
3. `scripts/validate_v1_2_release.mjs`：独立重算指标、检查关系、来源分层、URL、页面数据、清单哈希和 V1.1 不可变性。

`outputs/V1.2/workbook_preview` 是可重新生成的视觉验收附件，不是业务数据源。`project_state.json` 保存机器可读的当前正式版本、入口和验收摘要。

## 原则

- 原始证据只在 `01_数据抓取`；正式数据和规则只在 `02_数据清洗`；网页只在 `03_网页呈现`。
- V1.1 及更早版本保持只读。V1.2 构建器遇到历史目录会主动拒绝写入。
- CSV 是机器事实来源；Excel 和网页数据由同一批 CSV/BI 数据自动生成。
- 校验失败、公开包含临时访问参数或页面真实回读失败时，不得替换正式入口。
