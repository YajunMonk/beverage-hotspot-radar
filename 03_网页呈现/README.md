# 第三步：网页呈现

本目录只负责把第二步已经确认的 BI 数据集渲染成可阅读、可筛选的页面，不在前端重新定义或计算业务指标。

## 当前交付

- [打开本地 V1.2 网页](V1.2/index.html)
- [查看公开网页](https://yajunmonk.github.io/beverage-hotspot-radar/)
- [V1.2 页面说明](V1.2/README.md)
- [V1.2 页面验收记录](验收记录/2026-W30/V1.2/页面验收记录.md)
- 历史 V1.1 页面在本地 `V1.1/index.html` 只读保留，不进入当前公开源码包

## 页面包含什么

- 数据范围、来源边界、复核进度和质量状态；
- 去重事件、品牌内容、有效 N、中位数、P75、P90 和最大值；
- 产品动作、联名合作、品牌事件三大主题；
- 25 行重点标签指标，以及品类、原料、联名和促销结构；
- 3 条热点选题的热梗、白话解释、热因、品牌借势角度和原帖；
- 品牌、KOC、三方独立筛选，事件详情与 94 条品牌原始内容；
- 每条线索和证据都提供明确可见的单条小红书原文入口。

页面读取[处理后数据 V1.2](../02_数据清洗/处理后数据/V1.2/)。修改标签、主题、统计口径或结论时返回[第二步](../02_数据清洗/README.md)；只有样式、排版和交互调整才在本目录处理。
